# 🧠 Stocki – Assistant intelligent de tri et de rangement de fichiers

Stocki est un petit projet d'IA personnelle conçu pour aider à **organiser, trier et nettoyer automatiquement les fichiers d'un PC**.  
Il identifie les doublons, classe les fichiers par catégories (images, documents, archives…), et propose des actions intelligentes selon leur usage ou redondance.

---

## 🚀 Fonctionnalités principales

- 📂 Classement automatique des fichiers (PDF, images, ZIP, etc.)
- 🧠 Suggestions intelligentes basées sur les noms, tailles et types de fichiers
- ♻️ Détection de doublons
- 🔍 Analyse d’arborescence avec aperçu
- 🧹 Nettoyage proposé avec confirmation (jamais automatique)
- 🧾 Journalisation des actions réalisées

---

## 🛠️ Technologies utilisées

- Python 3
- `os`, `shutil`, `hashlib`, `tkinter` (ou autre interface si tu en as une)
- [Optionnel] intégration à une interface GUI minimaliste (Tkinter ou autre)
